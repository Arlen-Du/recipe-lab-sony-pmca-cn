# 汉化维护与上游同步指南

本项目基于 [voxivoid/recipe-lab-sony-pmca](https://github.com/voxivoid/recipe-lab-sony-pmca) 进行中文本地化适配。

## 一、架构设计理念：低侵入 & 零冲突

为了确保上游项目更新后能够轻松无痛地合入代码，汉化采用了**“UI 边缘拦截式”**架构设计：

1. **核心逻辑零修改**：`Params.java`、`Recipes.java`、`Favourites.java`、`DevTools.java` 内部计算和存储逻辑完全保持英文原样，既保证了自动化单元测试（`tools/test.sh`）严格通过，又避免了上游修改业务逻辑时产生大面积冲突。
2. **统一字典中心**：所有翻译词条集中在 [src/com/voxivoid/recipelab/I18n.java](file:///Users/arlen/CodeBuddy/recipe-lab-sony-pmca-cn/src/com/voxivoid/recipelab/I18n.java)。纯 Java 实现，脱离 Android SDK 单独编译并覆盖单元测试（[test/com/voxivoid/recipelab/I18nTest.java](file:///Users/arlen/CodeBuddy/recipe-lab-sony-pmca-cn/test/com/voxivoid/recipelab/I18nTest.java)）。
3. **安全回退机制（Fallback）**：遇到上游新增尚未翻译的文本时，会自动降级显示英文原文，绝不崩溃。
4. **UI 边缘注入**：仅在各 View 的 `onDraw` 绘制和 `MainActivity.showToast` 显示出口处包一层 `I18n.t(...)`。

## 二、如何同步上游更新并合代码

### 推荐方法：一键同步脚本

在项目根目录下直接运行：

```bash
./tools/sync-upstream.sh
```

该脚本会自动执行以下步骤：
1. 检查工作区是否干净。
2. 自动拉取上游（`upstream`）的最新代码。
3. 执行 `git merge upstream/main`。
4. 自动执行 `./tools/test.sh` 全量单元测试进行质量门禁校验。

### 手动同步步骤（若需要）

```bash
# 1. 确保添加了 upstream 源（脚本已默认配置）
git remote add upstream https://github.com/voxivoid/recipe-lab-sony-pmca.git

# 2. 拉取最新更新
git fetch upstream main

# 3. 合并到当前分支
git merge upstream/main -m "chore: sync upstream changes"

# 4. 运行单测验证
./tools/test.sh

# 5. 推送到自己的仓库
git push origin main
```

## 三、如何添加或修改汉化词条

直接修改 [src/com/voxivoid/recipelab/I18n.java](file:///Users/arlen/CodeBuddy/recipe-lab-sony-pmca-cn/src/com/voxivoid/recipelab/I18n.java)：

1. **静态词条**：在静态字典 `DICT.put("英文原文", "中文翻译")` 中增加映射。
2. **动态匹配消息**：在 `tToast(...)` 或 `tMenuLabel(...)` 中针对带变量的短语进行模式匹配。
3. **验证改动**：运行 `./tools/test.sh` 确保单元测试通过。
